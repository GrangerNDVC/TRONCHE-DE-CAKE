Les images sont chargées automatiquement quel que soit leur format (.jfif, .jpg, .jpeg, .png, .webp) — dépose juste le fichier avec le bon nom, pas besoin de convertir. Fond vert #00FF00 pour Perso 1, fond magenta #FF00FF pour Perso 2 (chroma-key retiré automatiquement). La marche et le saut ne s'activent que si les images perso-marche / perso-saut existent.
Les sons (musiques + bruitages) suivent le même principe : dépose les fichiers audio à côté de ce fichier html (.mp3, .ogg, .wav ou .m4a, extension détectée automatiquement) — le jeu fonctionne aussi sans eux.
